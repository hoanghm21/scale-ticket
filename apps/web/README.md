# @scale-ticket/web

The Next.js web client for ScaleTicket.

## Features

- 🎨 Interactive seat maps via Canvas API
- ⚡ Real-time seat availability via Socket.IO
- 🛒 Instant checkout with Stripe
- 🌙 Dark mode support
- 📱 Fully responsive

## Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
